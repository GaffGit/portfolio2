Drillhouse/

          
side project · 2026

        

        

          
problem
Poker training tools that grade you against solver strategies (like GTO Wizard) are expensive. I wanted my own drill trainer for 6-max No-Limit Hold'em.

          
role
Solo: product design, architecture, poker engine, UI and the solver data pipeline.

          
outcome
A web app that deals spots and grades every answer against solver solutions by EV loss: 35 preflop spots plus full hands played to the river. The poker engine is pure TypeScript: a 5–7 card hand evaluator, equity calculations, EV-based grading, and leak detection that groups your mistakes into patterns to replay. 188 unit tests. Solutions are generated offline with open-source solvers in Docker.

          
stack
TypeScript · Next.js · React · Tailwind · SQLite · Vitest · Docker

FoodRadar/

          
side project · 2026

        

        

          
problem
Checking what's for lunch at the University of Jyväskylä meant opening each student restaurant's menu page one by one.

          
role
Solo: designed and built the whole app.

          
outcome
A desktop widget that shows every campus restaurant's menu for the day at a glance, pulled from the Semma and Compass Group public menu feeds. Runs on plain Python with zero dependencies. Lets you browse by day, switch between Finnish and English, choose which restaurants to show, and start it with Windows.

          
stack
Python · Tkinter · Win32 API via ctypes · threading · REST/JSON
